# Task Management API

Асинхронный REST API для управления задачами, реализованный на FastAPI.
Проект выполнен в рамках тестового задания и демонстрирует работу с PostgreSQL,
слоистую архитектуру (API → Service → Repository) и контейнеризацию.

## Как работает
API предоставляет CRUD-эндпоинты для сущности "задача":
- создание, получение, обновление и удаление (soft delete);
- получение списка задач с фильтрацией и пагинацией.

Взаимодействие с базой данных осуществляется через асинхронный SQLAlchemy.
Вся бизнес-логика вынесена в сервисный слой.

## Документация API
Swagger-документация доступна по адресу:
http://localhost:8000/docs

## Запуск проекта

Требуется установленный Docker и Docker Compose.

```bash
docker compose up --build
```
После запуска сервис будет доступен по адресу:

http://localhost:8000
